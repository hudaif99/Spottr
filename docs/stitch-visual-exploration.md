# Spottr — visual exploration
11 October 2026. The user rejected the first warm editorial screen as too plain.

## Decision
Give Stitch freedom over visual direction while retaining product behavior and accessibility constraints. Generate three substantially different workout concepts, review them, refine the strongest, then rebuild DESIGN.md and tokens from the selected result. Previous exact styling is not a generation constraint. Preserve the first screen for comparison. No Flutter changes.

## Copy-ready exploration prompt

```text
Reimagine Spottr's Active Workout screen as THREE genuinely different visual concepts. The user rejected the source design as plain and unattractive. Use the source ONLY for product context; do not preserve its art direction. Previous DESIGN.md colors, Outfit font, card treatment, exact spacing, and layout are superseded for this exploration. You own the art direction: choose the palette, typography, icon treatment, composition, shapes and density. Do not merely recolor the same layout. Give each concept a short distinctive title outside the app UI.

Design ambition: a distinctive, beautiful, clean mobile training tool that feels satisfying to use between demanding sets. Find visual character through typographic hierarchy, confident proportion, a considered accent, purposeful controls, and a strong composition. Minimal does not mean bland. Explore three different answers to this brief without being constrained to a named aesthetic. At least two should be light concepts; a dark concept is acceptable as the third. Keep each concept realistically buildable as native Flutter for Android/iOS.

Fixed product task, same across all concepts:
- Dedicated active workout outside main tabs. Lower body workout in Strength — 3 days.
- Current exercise Cable kickback. Visible user setup note: Pulley at knee level.
- Set 2 of 3, prefilled weight 12.5 kg and 12 reps. Previous completed performance 12.5 kg × 12 reps.
- Overall 7 of 9 sets logged, elapsed 34 min. Earlier exercises Leg press 3/3 and Dumbbell Romanian deadlift 3/3, Cable kickback 1/3.
- Large minus/plus controls for weight/reps and direct numeric entry. One obvious Log set action logs these unchanged values in ONE tap.
- Distinguish prefilled values from completed work. Show completed Set 1: 12.5 kg × 12 reps, visibly logged, editable with undo/removal available through understandable options. Adding a set remains available.
- Labeled workout overview enables free exercise selection; do not force moving after completion. Session options/detail edits available; logged names can be locked.
- Finish accessible but separated from frequent logging; returning to Today retains resumable session. Discard separate destructive action.
- Ready state: no active countdown. Design so a compact rest countdown with Skip/+30s can appear without losing exercise context or preventing further logging. Do not show an inactive-timer explanation or fake countdown.
- kg only; no unit selector. Optional note is equipment context, not instruction generated by the app.
- Same realistic content in all three concepts so comparison measures design, not feature changes.

Usability guardrails:
390×844 logical-pixel reference including safe areas. >=48px targets, larger primary logging controls, readable contrast and labels; include main controls and action in initial viewport. Long names and 320px width must have a plausible reflow; don't make a mockup that requires microscopic text.
No athlete hero photo, exercise illustration, gradients/glass/glow, decorative achievement badges, dashboard statistics, motivational filler, repeated rounded-card grids, or generic fitness template. Do not add accounts, AI coaching, new records/charts, cardio duration/distance, supersets, or routine replacement/reordering.
Produce three standalone full app screens, no hardware frames or presentation boards. Prioritize visual design quality without compromising the tired-person logging task. Preserve the original screen and make new variants.
```
