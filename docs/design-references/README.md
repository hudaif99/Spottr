as reference input. Adapt the interface qualities; do not ship the reference photos,
phone hardware, branding, healthcare/nutrition content or artwork in Spottr.

The Stitch composer accepts image files, but automated filechooser events timed out.
Its Website URL control accepted both direct artwork URLs as attached references.
Stitch reported fetching both images and described content not supplied in the
inspection prompt: the healthcare appointment/discovery layout and Dr. Olivia
Bennett, plus the nutrition date strip, Daily Progress and 1250 / 2000 cal labels.
This establishes a substantially stronger visual-input workflow than text URLs
in an MCP generation prompt. It does not establish design quality by itself.
